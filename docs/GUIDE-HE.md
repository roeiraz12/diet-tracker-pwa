# יומן דיאטה

אפליקציה פשוטה לטלפון למעקב אחרי מה שאוכלים ואחרי המשקל.

- רושמים מאכלים ומתכונים במילון אישי.
- מוסיפים מה אכלתם בכל ארוחה, ורואים כמה קלוריות נשארו להיום.
- שוקלים את עצמכם ורואים גרף של ההתקדמות.
- האפליקציה מחשבת יעד קלורי יומי לפי הגיל, הגובה, המשקל, רמת הפעילות והמטרה.

## איפה הנתונים נשמרים?

**רק בטלפון שלכם.** אין שרת, אין הרשמה ואין סיסמה. אף אחד אחר לא רואה את הנתונים.

המשמעות: אם הטלפון אובד, מתאפס, או שמוחקים את נתוני הדפדפן – הנתונים נמחקים. לכן חשוב לשמור **גיבוי** (הסבר בהמשך).

> האפליקציה נותנת הערכות כלליות בלבד ואינה ייעוץ רפואי. לפני שינוי גדול בתזונה כדאי להתייעץ עם רופא או דיאטנית.

---

## לפתוח את האפליקציה במחשב (לבדיקה)

צריך שיהיה מותקן Python במחשב.

1. פותחים את התיקייה של האפליקציה.
2. לוחצים בשורת הכתובת של החלון, כותבים `cmd` ולוחצים Enter. ייפתח חלון שחור.
3. כותבים את הפקודה הבאה ולוחצים Enter:
   ```
   python -m http.server 8000
   ```
4. פותחים בדפדפן את הכתובת: `http://localhost:8000`
5. כדי לסגור – סוגרים את החלון השחור.

(פתיחה ישירה של הקובץ `index.html` בלחיצה כפולה לא תעבוד. צריך את השלב הזה.)

## לפרסם את האפליקציה כדי להשתמש בה בטלפון

כדי לפתוח את האפליקציה בטלפון היא צריכה כתובת באינטרנט. זה בחינם. יש שתי דרכים – מספיק לבחור אחת.

> גם כשהאפליקציה באינטרנט, **הנתונים שלכם נשארים רק בטלפון**. באינטרנט נמצאים רק קבצי האפליקציה עצמה.

### דרך א': GitHub Pages (מומלץ)

1. נכנסים ל-[github.com](https://github.com) ולוחצים **Sign up** כדי לפתוח חשבון (אימייל, סיסמה ושם משתמש).
2. אחרי ההתחברות לוחצים על **+** למעלה ואז **New repository**.
3. בשדה **Repository name** כותבים שם באנגלית, למשל `diet`.
4. בוחרים **Public** ולוחצים **Create repository**.
5. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
6. פותחים במחשב את תיקיית האפליקציה, מסמנים את **כל** הקבצים והתיקיות שבתוכה (Ctrl+A), וגוררים אותם לחלון של GitHub.
   - חשוב: לגרור את מה שבתוך התיקייה, ולא את התיקייה עצמה. הקובץ `index.html` צריך להיות ברמה הראשית.
7. מחכים שההעלאה תסתיים ולוחצים למטה **Commit changes**.
8. עוברים ללשונית **Settings** של ה-repository, ובתפריט בצד בוחרים **Pages**.
9. תחת **Build and deployment**: ב-**Source** בוחרים **Deploy from a branch**. ב-**Branch** בוחרים `main` ולידו `/ (root)`, ולוחצים **Save**.
10. מחכים 1–3 דקות ומרעננים את העמוד. למעלה תופיע הכתובת של האתר, בערך כך:
    `https://שם-המשתמש.github.io/diet/`
11. פותחים את הכתובת הזו בטלפון. אפשר לשלוח אותה לעצמכם בוואטסאפ או במייל.

### דרך ב': Netlify Drop (הכי מהיר)

1. נכנסים ל-[app.netlify.com/drop](https://app.netlify.com/drop).
2. גוררים את **כל תיקיית האפליקציה** לתוך העמוד.
3. אחרי כמה שניות מקבלים כתובת. כדי שהאתר לא יימחק אחרי זמן מה, צריך ליצור חשבון חינמי (האתר יציע את זה).

## להתקין את האפליקציה במסך הבית

אחרי ההתקנה האפליקציה נפתחת כמו אפליקציה רגילה, עובדת גם בלי אינטרנט, והנתונים שמורים טוב יותר.

### אייפון
1. פותחים את הכתובת ב-**Safari** (חובה Safari, לא כרום).
2. לוחצים על כפתור **השיתוף** (ריבוע עם חץ למעלה) בתחתית המסך.
3. גוללים ובוחרים **הוסף למסך הבית** (Add to Home Screen).
4. לוחצים **הוסף**.

### אנדרואיד
1. פותחים את הכתובת ב-**Chrome**.
2. לוחצים על **⋮** (שלוש נקודות) למעלה.
3. בוחרים **התקנת אפליקציה** (או **הוספה למסך הבית**).
4. מאשרים.

מעכשיו פותחים את האפליקציה מהאייקון הירוק במסך הבית.

## גיבוי – חשוב מאוד

כי הנתונים נמצאים רק בטלפון, כדאי לשמור גיבוי **פעם בשבוע**. האפליקציה תזכיר לכם.

**לשמור גיבוי:** הגדרות → **שמירת קובץ גיבוי**. נוצר קובץ בשם כמו `diet-backup-2026-11-19.json`. באייפון ייפתח חלון שיתוף – אפשר לשמור ב"קבצים", ב-iCloud, ב-Google Drive או לשלוח במייל לעצמכם.

**לשחזר מגיבוי** (למשל בטלפון חדש): פותחים את האפליקציה → הגדרות → **שחזור מקובץ גיבוי** → בוחרים את הקובץ. שימו לב: השחזור מחליף את כל הנתונים שיש כרגע באפליקציה.

## לעדכן את האפליקציה בעתיד

אם משנים קבצים באפליקציה ומעלים אותם שוב:

1. פותחים את הקובץ `sw.js` ומשנים את המספר בשורה:
   ```
   const VERSION = 'v1';
   ```
   ל-`'v2'` (ובפעם הבאה `'v3'` וכן הלאה).
2. מעלים את הקבצים המעודכנים לאותו מקום (ב-GitHub: **Add file** → **Upload files**, גוררים ולוחצים **Commit changes**).
3. בפעם הבאה שתפתחו את האפליקציה בטלפון יופיע הכיתוב "יש גרסה חדשה" עם כפתור **רענן**. לוחצים עליו.

בלי שינוי המספר ב-`sw.js` הטלפון ימשיך להציג את הגרסה הישנה ששמורה אצלו.

העדכון לא מוחק את הנתונים שלכם. ובכל זאת, כדאי לשמור גיבוי לפני.
